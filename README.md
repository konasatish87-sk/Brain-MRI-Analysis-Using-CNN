
# Brain MRI Analysis

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify Brain MRI images.

The application is developed using TensorFlow and Streamlit.

## Technologies Used
- Python
- TensorFlow
- CNN
- NumPy
- Streamlit
- Pillow

## Features
- Upload Brain MRI images
- Classify images using a trained CNN model
- Display class-wise prediction probabilities
- Interactive web interface

## How to Run

1. Clone this repository.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
